# Banking Transaction Analysis Using SQL

## 📌 Project Overview

The Banking Transaction Analysis project is a SQL-based data analysis project developed using MySQL. The project analyzes banking data related to customers, accounts, transactions, loans, employees, and branches.

The objective is to use SQL to answer real-world banking business questions and generate meaningful insights for data-driven decision-making.

## 🎯 Project Objective

The main objective is to analyze banking operations and customer behavior using SQL and identify patterns related to:

* Customer activity
* Account balances
* Transactions
* Loans
* Branch performance
* Customer relationships

## 🗄️ Dataset

The project contains:

| Table        | Records |
| ------------ | ------: |
| Branches     |      10 |
| Customers    |     100 |
| Accounts     |     150 |
| Employees    |      40 |
| Loans        |      50 |
| Transactions |   2,000 |

## 🔍 Business Analysis

The project answers business questions such as:

* Who are the top customers by transaction amount?
* Which branch has the highest account balance?
* Which account type is most popular?
* Who is the most active customer?
* What are the monthly transaction trends?
* Which customers have multiple accounts?
* Which customers have both loans and multiple accounts?
* Which branch has the highest loan activity?
* Which accounts are inactive?
* How do branches rank based on performance?

## 📊 Key Insights

The analysis provides insights into:

* High-value customers
* Customer transaction behavior
* Account usage
* Monthly transaction trends
* Branch performance
* Loan distribution
* Inactive accounts
* Customers using multiple banking products
